# Favorit Parts — Подбор аналогов автозапчастей

Демо: [artyomusov.github.io/Favorit/](https://artyomusov.github.io/Favorit/)

## Описание

Клиентское приложение для двухэтапного подбора автозапчастей через веб-сервис «Проценка» (Favorit Parts):

1. **Вводите артикул** — сервис возвращает список производителей.
2. **Выбираете бренд** — получаете таблицу аналогов с ценами, остатками и признаками возврата.

## Стек

- **React** 18 + **Redux Toolkit**
- **Bootstrap 5** для стилизации
- **Vite** для сборки
- **Vitest** для тестов (32 теста)

## Быстрый старт

```bash
npm install
npm run dev
```

Для продакшн-сборки:

```bash
npm run build
```

Тесты:

```bash
npm test
```

## Архитектура

```
src/
├── api/          # Работа с API Favorit Parts (fetch, URL-кодирование)
├── components/   # React-компоненты (форма, бренды, таблица, лоадер)
├── lib/          # Чистые функции: парсинг, форматирование, тесты
├── store/        # Redux-слайс: состояния загрузки, бренды, аналоги
```

## Ключ покупателя

Ключ покупателя обязателен для работы с API сервиса «Проценка». В демо-версии он вводится вручную в поле «Ключ покупателя» — это сделано намеренно, так как ключ, зашитый в сборку, стал бы публичным и мог быть исчерпан. Для локальной разработки ключ можно задать через `.env`.
